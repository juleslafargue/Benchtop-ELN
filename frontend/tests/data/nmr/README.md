# Real NMR files used by the tests

From cheminfo's public test collections, MIT licence:

- `jcamp-data-test` (Copyright (c) 2020 cheminfo): `aspirin_1h_topspin_ntuples.dx` (TopSpin's JCAMP-DX export of a
  processed spectrum), `aspirin_1h_fid.dx` (its FID), `cytisine_1h_mestrenova_blocks.jdx` (a MestReNova file with a
  structure, a peak list and the spectrum), `nanalysis_ibuprofen_1h_fid.jdx` (Nanalysis 60 MHz),
  `oxford_ethylcrotonate_1h_fid.jdx` (Oxford Instruments X-Pulse 60 MHz), `varian_1h.jdx`, `jeol_1h.dx`,
  `indometacin_1h.dx` (400 MHz, DMSO-d6). Stored gzipped.
- `bruker-data-test` (Copyright (c) 2022 cheminfo): `aspirin_1h_bruker_fid.zip` (raw FID),
  `aspirin_1h_bruker_processed.zip` (TopSpin's processed spectrum of the same experiment) and `ibuprofen_1h_bruker_fid.zip`
  (600 MHz raw FID).
